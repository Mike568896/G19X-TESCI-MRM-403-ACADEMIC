# MVP (Minimum Viable Product) - Pluri Uno

## 1. Alcance Real del MVP
- **Implementado:** Autenticación de usuarios, consultas y actualizaciones de obligaciones en SQLite, y control de roles básicos.
- **Fuera de Alcance (Simulado / Pendiente):** El almacenamiento físico real de archivos mediante Multer en servidor y el envío automático de notificaciones por correo (las alertas operan de forma visual en la interfaz).

## 2. Criterios de Cierre del MVP
- Funcionamiento estable de la persistencia de datos tras recargar la aplicación (F5).
- Despliegue y ejecución local documentada mediante el README.
